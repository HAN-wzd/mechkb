\# MechKB — 机械工艺知识库 RAG 问答助手



机械工程师查手册靠翻目录、靠关键词搜索，无法直接用自然语言提问。

MechKB 用 RAG（检索增强生成）让工程师直接提问，回答附带原文出处。
